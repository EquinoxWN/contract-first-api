## Audit finding (2026-11-01)

`npm audit` now reports GHSA-g3hv-75wg-m249 (moderate, published 2026-10-30) for `minimatch`
3.1.5, pulled in by `@stoplight/spectral-core` 1.24.0 (the latest release, which pins `^3.1.4`).
No 3.x fix exists and `npm audit fix` would downgrade Spectral to 0.0.0. Overriding to minimatch
11 breaks Spectral's `require("minimatch")` default import. The advisory describes
`firstPhasePreProcess` with `optimizationLevel >= 2`; neither exists in 3.1.5 (checked in
`node_modules/minimatch/minimatch.js`), and Spectral only calls minimatch for ruleset `overrides`,
which this ruleset does not use. `make audit` now runs `scripts/audit.mjs`: it fails on every
advisory except this one, and only while the installed version is exactly 3.1.5 (checked by
changing the pinned version to 3.1.4: exit 1).
